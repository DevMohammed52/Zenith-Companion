# Archived Features

This directory contains experimental pages and utilities archived from active production:

* `pages/combat/` - Legacy combat calculator and kill session tracker. Archived until official hunting formulas and enemy scaling factors are established.
* `pages/market-alerts/` - Legacy browser market watch and notification alert rules.
* `lib/market-alerts.ts` - Alert evaluation and vendor arbitrage logic (bartering vendor price comparisons). Preserved for future integration into `/skill-profit` or `/items`.
